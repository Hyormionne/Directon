## 4. 원인 진단: 번호 거절은 STT 문제

1차 측정에서는 번호를 "자리 수가 틀렸다"며 다시 묻는 경우가 가장 많았다. 원인을 보려고 debug 세션(`session.start`에 `"debug": true`)으로 8건을 다시 돌려 STT 결과와 실제 함수 인자를 확인했다. 7건에서 같은 현상이 재현됐다.

| 문항 | 고객이 말한 번호 | Soniox 결과 | 모델이 넣은 인자 | 처리 |
|---|---|---|---|---|
| P0052-02 | 01079044351 | `51375. 5499. 451.` | order_id `513755499451` | 막힘 |
| P0148-02 | 20261001-0005987 | `2026년 2020. 00987` | order_id `202000987` | 막힘 |
| P0032-09 | 01018167368 | `515110736` | 9자리 | 막힘 |
| P0034-03 | 010 5116 2731 | `516. 5166273` | 10자리 | 막힘 |
| P0196-02 | 01087638842 | `018738842` | 9자리 | 막힘 |

1. **번호 검증 로직은 정상이다.** 틀린 번호를 보내지 않도록 제대로 막았다.
2. **우리 파이프라인 탓이 아니다.** 원본 wav를 Soniox에 직접 넣어도 결과가 같다.
3. **Soniox 설정으로는 거의 안 바뀐다.** context를 빼거나, 번호 형식 설명을 넣거나, `language_hints_strict`를 켜도 7건 중 1건만 나아졌다.
4. **음성 자체가 숫자 부분을 알아듣기 어렵다.** 공식 채점이 쓰는 gpt-4o-transcribe도 "오유 삼지로 오사구구 사오인"(P0052-02)처럼 틀린다.

번호를 말하는 문항은 21개이고, 그중 발신자 정보가 있는 문항은 7개다. 발신번호가 있으면 프로그램이 교정할 수 있고(AG-T41), 없으면 되묻는 것이 맞다. 되묻는 경우엔 되묻는 말의 품질이 점수를 가른다(AG-T42).

## 7. 재현 방법과 결과 위치

```bash
# 1) mock 서버(공식 DB)
uv run python -m mock_api.server --port 8100
# 2) 상담원 서버(BAZE 경유 gpt-5.4-mini, 대체 TTS 끔)
LLM_PROVIDER=openai OPENAI_MODEL=gpt-5.4-mini OPENAI_API_KEY="" GEMINI_LLM_FALLBACK_MODELS=none \
DIRECTON_TTS_FALLBACK=none uv run python -m agent.server --port 9001
# 3) 측정·채점 (directon-2026-voice-cs/eval 에서)
uv run python run_eval.py --server ws://localhost:9001 --mock http://localhost:8100 \
  --cases ../data/practice_cases.jsonl --audio ../data/audio/practice --out ../../runs/<이름>
uv run python score.py --run ../../runs/<이름> --cases ../data/practice_cases.jsonl --no-judge
```

- `OPENAI_API_KEY=""`는 BAZE 경유를 강제하려는 설정이다. 비워 두면 BAZE_API_KEY를 쓴다.
- 이번 측정에서 9000번 포트는 출처를 모르는 다른 상담원 서버가 쓰고 있어서 9001번을 썼다.

| 위치 | 내용 |
|---|---|
| `runs/official_t42_merged/` | 2차 최종 결과(`results.jsonl`, `scored.jsonl`, `summary.json`, `ux_scores.json`) |
| `runs/official_baze_gpt54mini_merged/` | 1차 최종 결과(같은 구성) |
| `runs/official_t42/`, `runs/official_t42_rerun3/` | 2차 원본과 재실행 3건 |
| `runs/official_baze_gpt54mini/`, `runs/official_baze_gpt54mini_rerun21/` | 1차 원본과 재실행 21건 |

`ux_scores.json`에는 문항별 A~F 점수, 즉시 0점 사례, 근거 한 줄이 있다. `runs/`는 저장소에 올리지 않는다(.gitignore). 대회 데이터는 대회 밖으로 옮기지 않는다(DATA.md).

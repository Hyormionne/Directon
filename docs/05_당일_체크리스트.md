# 05. 당일 체크리스트 (2026-11-21)

> AG-T17. 코드 수정 없이 공식 자료를 끼워 넣고, 리허설 뒤 측정 모드로 띄우는 순서. 명령은 저장소 루트에서 실행한다(Git Bash 기준, PowerShell은 `export X=Y` → `$env:X="Y"`).

## 0. 전날 밤

- [ ] `uv sync`, `uv run pytest -q` 통과
- [ ] `.env`에 API 키(측정에 쓸 Provider) 확인. 키를 문서·채팅에 붙이지 않는다
- [ ] `cloudflared` 설치 확인(`scripts/tunnel.sh` / `scripts/tunnel.ps1`)
- [ ] `official/` 폴더 비워 두기(당일 자료 자리, 커밋하지 않는다)

## 1. 09:00 자료 받기 (~10분)

공식 자료를 `official/`에 저장한다. 파일 이름은 아래로 맞춘다.

| 자료 | 저장 위치 | 쓰는 곳 |
|---|---|---|
| 응대 매뉴얼 | `official/manual.md` (PDF·docx면 텍스트로 옮겨 붙인다) | `DIRECTON_MANUAL` |
| 함수 정의 | `official/tools.json` | Mock `--tools` → 상담원은 `GET /tools`로 받음 |
| Mock 데이터 | `official/mock_data.json` | Mock `--data`, 카탈로그·번호 자릿수 |
| 브랜드 소개(있으면) | `official/brand.md` | `DIRECTON_BRAND` |
| 말투 가이드(있으면) | `official/style.md` | `DIRECTON_STYLE` |

- [ ] JSON이 열리는지: `uv run python -c "import json;json.load(open('official/tools.json',encoding='utf-8'));json.load(open('official/mock_data.json',encoding='utf-8'))"`
- [ ] 함수 정의 형식: `[{name, description, parameters}]`와 `[{"type":"function","function":{...}}]` 둘 다 읽는다
- [ ] 데이터 형식: 우리 쇼핑몰 형식(members·orders·products …) 또는 Starter Kit 매핑 형식(`{함수명: [{"arguments":…, "result":…}]}`). 그 밖의 형식이면 매핑 형식으로 변환하는 스크립트를 먼저 만든다

## 2. 교체 (~5분, 코드 수정 없음)

```bash
export DIRECTON_MOCK_DATA=official/mock_data.json   # Mock·카탈로그·번호 자릿수가 같이 따라간다
export DIRECTON_MOCK_TOOLS=official/tools.json
export DIRECTON_MANUAL=official/manual.md
export DIRECTON_BRAND=official/brand.md             # 없으면 지정하지 않는다
export DIRECTON_STYLE=official/style.md             # 없으면 지정하지 않는다

uv run python -m mock_api.server --port 8100        # 시작 줄에 tools 수, shop/mapping, 경로가 찍힌다
uv run python -m agent.server --port 9000           # 다른 터미널, 같은 환경변수
```

- [ ] Mock 시작 줄의 함수 개수가 공식 정의와 같다
- [ ] 번호 자릿수 확인: `uv run python -c "from agent.catalog import order_id_lengths,phone_lengths;print(order_id_lengths(),phone_lengths())"` → 공식 데이터의 주문번호 길이(예: `frozenset({4})`)
- [ ] 프롬프트 확인: `uv run python -c "from agent.prompts import fixed_prompt;print(fixed_prompt())" | grep 자리` → 그 자릿수로 적혀 있다
- [ ] 우리 쇼핑몰 함수 이름(get_order_info 등)과 공식 이름이 다르면, 프롬프트의 함수 이름 규칙(`agent/prompts.py` 고정부)은 공식 이름으로 맞춰야 한다 → 이 경우만 코드 수정(트랙 문서에 기록)

## 3. 스모크 (~10분)

- [ ] 함수 하나 직접 호출: `curl -s -X POST localhost:8100/tools/<함수명> -H "X-Session-Id: smoke" -d '<공식 예시 인자 JSON>'` → 정의된 출력, `curl -s "localhost:8100/calls?session_id=smoke"`에 `matched: true`
- [ ] 데모 음성 3개: `uv run python "DIRECT_ON 2026 Starter Kit/eval/run_eval.py" --server ws://127.0.0.1:9000 ...`(Starter Kit README 명령) → 세 문항 모두 `turn.end`, 첫 소리 > 0(말 끝 전 발화 없음)
- [ ] 브라우저 데모로 1통화(`docs/03_사용자_테스트_가이드.md`): 매뉴얼 정책 질문 1개, 주문 조회 1개, 상담원 연결 1개

## 4. 외부 접속 (~5분)

```bash
bash scripts/tunnel.sh 9000          # Windows: powershell -File scripts/tunnel.ps1 9000
```

- [ ] 출력된 `wss://…trycloudflare.com` 주소로 데모 음성 1개 재측정(`--server wss://…`)
- [ ] 주소를 운영진에 전달. 측정이 끝날 때까지 터널·서버·Mock을 끄지 않는다

## 5. 동시 4세션 리허설 (~15분)

운영진이 시험 데이터를 주기 전, 우리 테스트셋으로 측정기와 같은 부하를 건다.

```bash
uv run python -m eval.stress --server wss://<터널 주소> --sessions 4 --rounds 2 --mock http://127.0.0.1:8100
```

- [ ] 실패 0, 말 끝 전 발화 0
- [ ] 서버 메모리가 회차마다 계속 늘지 않는다
- [ ] 공식 데이터로 바꾼 상태라 우리 테스트셋의 함수 결과는 not_found가 많다 → 여기서는 안정성·속도만 본다

## 6. 측정 모드로 재시작 (측정 30분 전)

측정 중에는 수정·재시작 금지. 아래로 한 번 띄우고 손대지 않는다.

```bash
export DIRECTON_NO_AUDIO_LOG=1       # 시험 음성 저장 금지: 턴 로그에서 고객 발화 원문을 지운다(시간 지표는 남김)
# 2절의 DIRECTON_MOCK_* / MANUAL / BRAND / STYLE 그대로
uv run python -m mock_api.server --port 8100
uv run python -m agent.server --port 9000
bash scripts/tunnel.sh 9000
```

- [ ] 서버 출력을 파일로 돌리지 않는다(`> log.txt` 금지). 콘솔 로그에 숫자 인식 교정 줄(고객 발화 일부)이 찍힐 수 있다
- [ ] 받은 시험 데이터 파일·음성은 `official/` 밖 어디에도 복사하지 않고, 측정 뒤 지운다
- [ ] 측정 직전 데모 음성 1개로 마지막 확인 → 터널 주소가 바뀌지 않았는지 확인

# 1차 리포트 — 한국어 음성 CS 에이전트 (DIRECT:ON 2026)

> 작성일 2026-11-19 · 기준 커밋 `90f321f` · 상세 기록은 `docs/AGENT_PLAN.md`(트랙 문서)와 `docs/decisions/*`

## 1. 요약

- 대회 규격(측정기 WebSocket, 16kHz PCM, 응대 50 / 함수 20 / 속도 30)에 맞춘 상담원 서버가 **끝까지 동작**한다. 172문항 실측에서 에러 0건.
- 1차 최적화로 172문항 기준 **속도 67.4 → 85.6, 함수 56.4 → 74.4, 추정 점수(응대 제외) 63.0 → 81.1**.
- 가장 큰 남은 손실은 **말 끝 전 응답 23건(13%)** — 숫자를 끊어 읽는 쉼, 긴 쉼, 자기 정정. 일부는 구조적 한계(1.1초 넘는 쉼, "완결처럼 들리는 문장 + 쉼 + 추가 요청")다.
- 지금까지 외부 API 비용은 **Gemini 약 $11(범위 $7~15)** 로 추정한다(결제 콘솔 확인 필요).

## 2. 대회 조건과 설계 방향

| 항목 | 내용 | 설계 대응 |
|---|---|---|
| 입력 | 측정기가 `session.start` 후 20ms PCM을 실시간 전송, 말 끝 뒤에도 무음 계속 | 말 끝 탐지를 직접 구현(VAD + 턴 결정기) |
| 속도 채점 | 말 끝 → 첫 유성음, 1.5초 이내 만점, 0.5초 단위 구간, **말 끝 전 소리 = 0점** | 캐시한 첫 마디를 확정 즉시 송신(확정 후 약 10ms). 목표를 "최소 대기"가 아니라 "1.5초 안에서 잘못 끊기 최소"로 설정 |
| 함수 채점 | 함수명 + 키 인자 정확 일치, `X-Session-Id` 필수 | 인자 정규화(한국어 숫자·철자·날짜), 번호 교정, 상품명·옵션 카탈로그 정규화 |
| 대화 형태 | 세션당 고객 발화 1회 → 응답 1회 → `turn.end`, 이전 대화는 `history` 텍스트 | 다중 턴 확인 플로우 대신 history 활용 |
| 데이터 | 공식 14개 함수·매뉴얼 미공개 | 가상 쇼핑몰 "다이렉트몰" 함수 14개·데이터·매뉴얼을 가정해 구현(공개 시 데이터만 교체) |

## 3. 현재 구성

```
측정기 ─WS─▶ 세션 ─┬─ STT: gemini-3.5-transcribe-live (부분 결과 숫자 복원)
                  ├─ VAD: Silero(ONNX) → 턴 결정기: 텍스트 규칙 × 발화 길이 표(보정값)
                  ├─ 확정 즉시: 캐시 첫 마디(상황별 3종) 송신
                  ├─ LLM: gemini-3.5-flash-lite (폴백 3.1-flash-lite), 선호출·첫 문장 선합성
                  ├─ 함수: Mock API 호출(정규화·번호 교정·자릿수 검사·인계 안전망)
                  └─ TTS: edge-tts SunHi(16k 변환, 레벨 정규화) → PCM + agent.transcript + turn.end
```

- 코드: Python 3.12, 약 11,700줄(agent/eval/mock_api/scripts), 테스트 21개 파일 **777개 통과**.
- 모든 외부 서비스는 인터페이스 뒤에 있어 교체 가능: Soniox STT·OpenAI LLM·Gemini TTS 어댑터 구현 완료(키가 생기면 환경변수로 전환).

## 9. 남은 문제와 리스크

1. **말 끝 전 응답 23건** — 숫자 묶음 사이 쉼 11, 발화 중 쉼 6, 자기 정정 4. 1.1초 넘는 쉼과 함정 문장은 1.5초 예산 안에서 구조적으로 구분이 어렵다.
2. **LLM 혼잡** — 측정 시간대에 flash-lite가 거의 매번 2.5초를 넘겨 폴백. 응답 종료 p50이 3.1초 → 6.0초. 속도 점수엔 영향 없지만 첫 마디 뒤 공백이 길어 응대 품질에 불리.
3. **숫자 인식** — 전화 채널에서 63~68%. STT 교체 없이는 개선 한계. 자릿수가 틀리면 되묻도록 프롬프트에 반영함.
4. **응대 점수 미측정** — 실서버 172문항에 judge를 아직 돌리지 않음(오프라인 73.0).
5. **환경 차이** — 테스트 음성은 모두 합성음. 실제 평가 음성(사람 녹음 여부, 쉼 길이, 잡음)에 따라 턴 보정값이 달라질 수 있다.
6. **공식 규격 미확정** — 허용 API, 서버 실행 위치, 응대 채점 방식, 공식 14개 함수.
7. **Starter Kit 데모 meta.json** — speech_end가 실제 음성과 맞지 않음(운영진 확인 필요).

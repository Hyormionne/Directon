## 3. 스위치별 trade-off

### 3.1 결과 템플릿 `DIRECTON_TOOL_TEMPLATE=1` — 켠다
- **얻는 것**: 조회 뒤 본 응답 p50 **2.3 → 1.0초**(best-tj 0.76초), 측정기 정의 p95 2.3 → 1.0초(모든 함수 문항이 1.5초 100점 구간). 공식 속도(채움말 제외) 85.7~86.4 → **89.3~89.4**(+3.3, 시스템 점수 약 +1). 인계 턴도 "상담원에게 연결합니다."가 먼저 나가 불만 문항 확정 → 본 응답 p50 2.3~2.7초 → 1.8초.
- **잃는 것**: 측정기 정의 p50은 0.14 → 0.40초(채움말이 템플릿에 밀려 취소됨, 점수 영향 없음). 문장이 기계적이다("확인해 보니 현재 환불완료 상태입니다", "배송중입니다"). LLM이 `_already_said` 때문에 **세부를 빼먹거나**(연습판 H0004: 바뀐 주소를 다시 말하지 않음 → judge 0) **같은 말을 반복**한다(H0024: "입금이 확인되었습니다. 입금이 확인되어…"). 172에서 judge·함수 손실은 잡음 폭 안(71.3 vs 70.1 평균).
- 비용: TTS 요청 +55/172(edge 무료), LLM 변화 없음.

### 3.2 첫 마디 정책 `DIRECTON_OPENER_ADAPTIVE=1` — 켠다(UX 근거, 시스템 점수 중립)
- **우리 테스트셋에서는 하는 일이 거의 없다.** 172턴 모두 `answer_ready=False`(확정 순간에 선합성 답이 준비된 적 0회) → 첫 마디 사용률 100%, 고른 첫 마디도 base와 172/172 같다(조회 100·단순 65·사과 7). 단일 턴이라 "직전 첫 마디 반복 금지"도 발동하지 않는다.
- 측정 차이: judge 65.8·67.8 vs base 72.1·68.1(평균 −3.3, A/A 차이 4.0 안). 함수·속도·인계 같음. 채움말 선택이 달라 조회 뒤 첫 유성음 p95가 2.26 → 1.92초로 약간 짧았다.
- **켜는 이유**: 공식 평가 사용자 경험(50점)의 감점 사례가 "모든 답변에 같은 채움말 반복"이다. 정책은 다중 턴에서 직전 첫 마디를 쓰지 않고 채움말이 첫 마디와 겹치지 않게 고른다. 시스템 점수 비용이 측정되지 않았으므로 UX 쪽 이득을 택한다. 다중 턴 효과는 이 측정으로 확인하지 못했다(데모 S17 시나리오로 사람이 확인 필요).

### 3.3 Jev 인계 `DIRECTON_JEV_HANDOFF=1` — 켠다
- **얻는 것**: 인계 재현율 13/16(base 2회 모두) → **15/16**(jevhandoff·best·best-tj). Jev가 인계로 고른 16턴(transfer 13 + 영업시간 외 callback 3)은 **모두 정답**, 오탐 0. LLM이 놓치던 T0038(화난 배송 불만 → LLM은 배송 조회만), T0041(이중 결제)을 잡았다. 남은 1건 T0042는 말 끝 전 발화(턴 결정기 문제).
- **잃는 것**: 인계 턴은 힌트 없이 시작한 선호출을 버리고 다시 부르므로(16~17턴) 불만 문항 확정 → 본 응답 p50이 2.3~2.7 → 2.95초로 늘었다(템플릿과 같이 켜면 1.8초로 상쇄). Jev 호출 문항당 약 5.5회(선호출 텍스트가 바뀔 때마다 요청). Jev 지연 p50 180ms / p95 250ms. 장애 구간에서는 1초 시간 초과 54회가 났지만 시간 초과면 기존 동작으로 돌아간다.
- 비용: Jev 단가 미확인(호출 수만 기록). LLM 호출은 거의 같다(+1%).

### 3.4 Jev 말 끝 `DIRECTON_JEV_TURN=1` — 끈다
- **효과 0**: 말 끝 전 발화 같은 11문항, 확정 대기 p50 694 → 696ms, 172턴 중 Jev 규칙(jev_hold/jev_fast)이 결정을 바꾼 턴 0. 기본 정책이 "p≤0.3이면 대기 연장"뿐인데, 남은 11건은 텍스트상 완결된 함정 쉼이라 Jev도 끝났다고 본다(AG-T24 오프라인 결론과 같다).
- 비용: Jev 문항당 5.1회, 판정 실패 시 시간 초과 위험. 얻는 것이 없으므로 끈다.

### 3.5 조합
- best-tj(템플릿+Jev 인계)와 best(+첫 마디 정책)는 잡음 폭 안에서 같다(시스템 79.1 vs 79.8, 함수 82.6 vs 80.8, judge 69.7 vs 72.1). 구조 지표(조회 뒤 답 0.76~0.94초, 인계 15/16, 오탐 0)는 둘 다 같은 수준.
- best에서 말 끝 전 발화 1건 증가(T0099, 긴 발화를 3.6초 일찍 확정)는 턴 결정 경로가 같으므로 STT 부분 결과 타이밍 잡음으로 본다.

# 채택 제안서: 당일 상담원 설정을 권장안(R2-best)으로 확정한다

> 2026-11-20 · 근거: `docs/decisions/round2.md` 외 결정 문서, 결과보고서 `docs/09_결과보고서.html`

## 1. 제안
당일 서버를 **R2-best 설정**으로 띄운다. 이 설정은 172문항에서 시스템 점수 **79.8**(최종 점수 20점 중 16.0)을 받았다. 같은 문항에서 단순 조합(STT+LLM+TTS)은 56.5였다.

```
DIRECTON_TOOL_TEMPLATE=1   DIRECTON_JEV_HANDOFF=1   DIRECTON_OPENER_ADAPTIVE=1   DIRECTON_NO_AUDIO_LOG=1
(기본값 유지: POST_TOOL_HEDGE=1, BARGE_IN=1, LLM_MODE=hedge, LLM_CONTEXT_CACHE=1, JEV_TURN 끔)
```

## 2. 시도한 것과 결과

**판단 기준:** 같은 설정을 두 번 돌려도 시스템 점수는 ±2.5점, 응대 점수는 ±4점 흔들린다. 그래서 점수 차이보다 지연 시간, 말 끝 전 발화 수, 인계 재현율로 판단했다.

| 시도 | 결과 (172문항) | 판단 |
|---|---|---|
| 말 끝 판단 대기 중 답 미리 만들기 (LLM 선호출, 첫 문장 음성 선합성) | 속도 점수 25.2 → 85.6 | 유지 (가장 큰 효과) |
| 말 끝 판단 표 보정 (2회) | 말 끝 전 발화 55 → 23 → 11건 | 유지 |
| LLM 동시 요청 + 컨텍스트 캐시 | 첫 응답 p95 3.73 → 1.64초, 비용 −70% | 유지 |
| 조회 뒤 LLM 호출도 동시 요청 | 조회 뒤 LLM 첫 응답 최대 4.4 → 2.0초 | 유지 |
| **조회 결과 템플릿** | 조회 뒤 실제 답 p50 2.33 → 0.99초, 공식 속도 85.7 → 89.4 | **켬** |
| **Jev 인계 판단** | 인계 재현율 13 → 15/16, 오탐 0 | **켬** |
| **상황별 첫 마디 정책** | 시스템 점수 변화 없음(오차 범위 안) | **켬** (UX 감점 사례 대응) |
| Jev 말 끝 판단 | 결정이 바뀐 턴 0, 말 끝 전 발화도 그대로 11건 | **끔** |
| 바지인과 송신 페이싱 | 끼어들면 300ms 안에 멈춤, turn.end 최대 12.7초(측정기 한도 25초 안) | 유지 |

## 3. 왜 이 조합인가
- **템플릿:** 함수 문항의 속도 점수 절반은 "조회 결과 → 실제 답" 시간으로 정해지는데, 측정한 것 중 이 시간을 1초 아래로 내린 것은 템플릿뿐이다. 함수 문항 p95가 1.02초가 되어 모두 100점 구간에 든다.
- **Jev 인계:** 이전 LLM 판단이 놓치던 화난 배송 불만(T0038)과 이중 결제(T0041)를 잡았다. 오탐은 0건이다. 인계 기준 6개가 코드에 임계값으로 적혀 있어 기획서와 발표에서 "Human Handoff 기준"을 그대로 설명할 수 있다.
- **첫 마디 정책:** 시스템 점수는 잃지 않는다. 직전 턴과 같은 첫 마디를 쓰지 않으므로, 공식 사용자 경험 평가(50점)의 감점 사례인 "같은 채움말 반복"을 피한다.
- **세 가지를 모두 켠 R2-best**가 가장 높은 점수(79.8)를 받았다. 조회 뒤 실제 답 0.94초, 인계 15/16도 함께 유지했다.

## 4. 감수하는 것
- **템플릿 문장이 기계적이다.** 템플릿 뒤에 LLM이 세부를 빠뜨리거나 같은 말을 반복할 때가 있다(연습판 H0004, H0024).
- **Jev를 질문당 약 5.5회 부른다.** 단가는 아직 확인하지 못했다. 인계 턴의 답은 0.3~0.5초 늦어지지만 템플릿이 이를 상쇄한다. Jev가 시간 초과되면 기존 LLM 판단으로 돌아간다.
- **첫 마디 정책의 효과는 측정하지 못했다.** 테스트 문항이 한 번 묻고 끝나는 형식이라, 여러 턴에서의 효과는 데모에서 사람이 확인한다.

## 5. 이번 채택으로 해결되지 않는 위험
| 위험 | 대응 |
|---|---|
| 음성 합성 대체 모델(gemini-3.8-flash-tts)의 하루 100회 한도가 소진됨. edge-tts가 멈추면 대체도 실패한다 | 당일 오전에 Gemini TTS를 쓰지 않는다. 대체 모델 교체는 별도 결정 |
| 4자리 주문번호에서 STT가 앞자리 "일"을 빠뜨림(연습판 함수 실패 6건 중 5건) | 공식 데이터의 자릿수를 확인한 뒤 자릿수 검사로 되묻게 한다 |
| 남은 말 끝 전 발화 12건, 잡음 문항에서 첫 소리 1.5초 초과 13건 | 바지인으로 피해를 줄인다. 구조적 한계로 기획서에 적는다 |

## 6. 요청
1. R2-best를 당일 기본 설정으로 확정한다(`.env`와 당일 체크리스트에 반영).
2. TypeSafe 대시보드에서 Jev 단가를 확인한다. 예산을 넘으면 `DIRECTON_JEV_HANDOFF`만 끈다. 이 경우 인계 재현율은 13/16으로 돌아가고, 나머지 효과는 그대로다.

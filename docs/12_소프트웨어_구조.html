저장소 구성

막대는 코드 줄 수(.py·.js·.html·.css) 비율입니다. 점선 칸은 원본 보관용이라 수정하지 않습니다.

구조를 지키는 규칙

  • 모듈 사이 계약은 agent/core/types.py 한 곳. STTProvider·TTSProvider·LLMProvider·VAD·SmartTurn·TurnDetector Protocol과 SessionInfo·Message·TurnSignals 데이터.
  • PCM은 어디서나 16kHz s16le mono. 24kHz(Gemini·BAZE TTS)나 MP3(edge-tts)는 Provider 경계에서 변환.
  • server.py는 Provider를 build_deps() 안에서 늦게 import하고, 테스트는 fake deps로 handle(ws, deps)만 검증. 네트워크 테스트는 @pytest.mark.live.
  • VAD·결정기·STT 스트림은 세션마다 새로 만들고, Provider·캐시·Smart Turn은 세션 사이에 공유.
  • 세션 안 예외는 밖으로 내지 않음. 실패하면 캐시 사과 + turn.end, 결정기가 죽으면 RMS 기준 비상 모드.
  • 함수 호출에는 항상 X-Session-Id(tools_client.py).
